# Registration Postcard UI Assets

These SVGs are reusable decorative pieces for the registration participation cards.

- `tape.svg` — masking tape accent for postcard/photo frames.
- `pin.svg` — brass pin accent for postcard/photo frames.
- `botanical-flourish.webp` — soft watercolor botanical/heart flourish for support or donation cards, on a flat `#FAF8F5` background.
- `botanical-flourish.png` — PNG fallback/source version of the same flourish.

Keep the actual photo assets separate from the postcard frame. The frame, tape, pin, rotation, and handwritten labels should be composed in the UI so the same photos can be reused responsively across desktop and mobile.
