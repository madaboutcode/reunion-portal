# Mobile Participation Postcard Mockup

Date: 2026-06-04

## Context

The desktop postcard direction is the strongest visual route for the new first registration step. The next mockup should explore how to preserve that “campus to Raviz night” arc on mobile without moving into implementation or HTML.

## Considered

- Shrink the desktop postcard layout directly.
- Use one image-heavy hero card for the complete experience.
- Use stacked mobile option cards with compressed postcard thumbnails.
- Use a bottom-sheet or segmented-control selection model.

## Chosen

Use stacked mobile option cards. Keep the complete experience selected by default, use postcard thumbnails inside that card, and compress the schedule into three chapters: campus morning, move to Raviz, evening and night.

## Why

The mobile job is to make the split obvious: campus-only ends before Raviz, while the complete experience continues into concert, dinner, DJ night, and relaxed reunion time. A chaptered postcard card keeps that emotional contrast visible without forcing tiny schedule text.

## Limitations

This mockup should not show the full schedule line-by-line. The schedule page already does that. This step should help the user choose the right participation path.

## Note

Do not create HTML for this stage. Keep output to image mockups until implementation is explicitly requested.

## Reversal

If the selected card no longer makes the inclusions clear enough, add a compact “View full schedule” accordion in the implementation rather than expanding every event into the default mobile view.
